Every asset here was checked on its source page and is **CC0 1.0 (public domain)**. Attribution is not required; it is recorded so we can trace where each file came from.
Kenney packs were taken from their official OpenGameArt mirrors because kenney.nl blocks scripted downloads. Each pack's bundled `License.txt` also says CC0.
GLB files that we made with Blender (headless) sit next to their source files and are derivatives of those CC0 assets.
